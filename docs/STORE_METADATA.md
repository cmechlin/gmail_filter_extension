## Draft Description

Gmail Filter Manager helps reduce the friction of managing Gmail labels and filters by putting common workflows into a Chrome side panel. Review existing filters, create labels, bulk-apply labels to matching messages, and move filter and label configurations in and out of Gmail.

## Key Features

- View current Gmail filters in one place
- Create and delete Gmail filters
- Create, rename, and delete Gmail labels
- Bulk-apply labels to existing messages
- Export and import filter and label configurations
